# Contributing

Thank you for helping with docs.tapyr.eu.

## Where does my change go?

- **The text of a page** (a typo, a wrong example, a missing page): [Kentrow/tapyr](https://github.com/Kentrow/tapyr). The pages are written there, next to the code they describe, and this repository never edits them. Pages are published from the `docs/site.yml` manifest of that repository.
- **The site** (theme, home page, navigation, search, versions, build, deployment): here.

## Working on the site

Build it locally as the [README](README.md#build-locally) shows, then before opening a pull request:

```sh
python -m unittest discover -s tools
python tools/site_tool.py prepare --tapyr tapyr --ref main --version dev --out build
zensical build --strict -f build/mkdocs.yml
python tools/site_tool.py check-links build/site
```

Look at the pages you changed in the light and the dark theme. For a change to versions or deployment, try `tools/site_tool.py publish` without `--push`: it commits to a local `gh-pages` branch only.

Commits follow [Conventional Commits](https://www.conventionalcommits.org/). Agents follow [`AGENTS.md`](AGENTS.md).

## Contributions assisted by AI

Coding agents are welcome, with the rules of Kentrow/tapyr: you submit only what you have read and understood, you run the checks yourself, you say in the pull request description that an agent helped and for what, and you add no co-author or "generated by" trailer to commits.
