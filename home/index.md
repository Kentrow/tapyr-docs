# Tapyr documentation

Tapyr is an open source, self-hosted gateway that turns the REST APIs of cloud-managed network gear into Prometheus and OTLP metrics. One declarative definition per API, in YAML and CEL, and every call planned against the vendor's rate limits and quotas.
