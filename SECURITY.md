# Security policy

This repository builds and deploys docs.tapyr.eu, a static site: no server code, no secret, no user data.

## Reporting a vulnerability

**Do not open a public issue.** Report it privately through GitHub: on the repository page, **Security**, then **Report a vulnerability**. Only the maintainers see the report. If you cannot use it, write to [conduct@tapyr.eu](mailto:conduct@tapyr.eu) with "security" in the subject, without the details: a maintainer answers with a way to share them privately.

In scope: the build and deployment workflows, the theme and its scripts, anything that could let a third party change what docs.tapyr.eu serves.

A vulnerability of Tapyr itself follows the [security policy of Kentrow/tapyr](https://github.com/Kentrow/tapyr/blob/main/SECURITY.md).
